worCalc - Windows Setup
=======================

Requirements
------------

- Windows 10/11
- Python 3.12 with the Python Launcher
- Internet access for the initial dependency install

Setup
-----

Extract the archive, open PowerShell in the extracted directory, and run:

    py -3.12 -m venv .venv
    .\.venv\Scripts\python.exe -m pip install -r requirements.txt

Launch
------

    .\.venv\Scripts\python.exe -m worcalc

For subsequent launches, only the launch command is required.

LAN web calculator
------------------

To serve the browser calculator to devices on the same network, run:

    .\.venv\Scripts\python.exe -m worcalc.web

Open http://localhost:8000 on this computer. To open it from a phone, run
"ipconfig", find this computer's IPv4 Address, and browse to port 8000 at that
address, for example:

    http://192.168.1.20:8000

If Windows Firewall asks, allow Python on private networks. This server has no
login and should only be used on a trusted local network.

Remote web calculator through Tailscale
---------------------------------------

Use the "worCalc Remote" desktop shortcut to open the small server controller.
Click Start and approve the Administrator prompt to enable private access. The
window shows whether the service is running and provides buttons to open or stop
it. Closing the controller does not stop the server; reopen it and click Stop
when finished.

Double-click START_REMOTE_WORCALC.bat and approve the Administrator prompt.
The launcher starts worCalc on localhost, waits for it to become ready, and runs
"tailscale serve --bg 8000". It then prints the private HTTPS address to open on
your phone. Tailscale must already be installed, connected, and signed in on both
devices. The PC must remain powered on; the Python server runs without a console
window until it is stopped. The launcher remains visible so it can show the
private address and any startup errors. Python output is saved in
%TEMP%\worcalc-web.log.

When finished, double-click END_REMOTE_WORCALC.bat and approve the Administrator
prompt. It disables only the Tailscale Serve endpoint created by the launcher and
then stops the worCalc web server. It will not stop an unrelated program that is
using port 8000.

Map data
--------

Game assets and PAK-derived map data are intentionally excluded from this
archive. Generate the required runtime files directly from an installed War of
Rights Assets directory:

    .\.venv\Scripts\python.exe extract_assets.py "D:\path\to\War of Rights\Assets"

The path may point either to the Assets directory itself or to its parent
War of Rights game directory. The extractor reads:

    Assets\Minimaps_*.pak
    Assets\LevelsLooseFiles.pak
    Assets\Levels\<Battlefield>\level.pak

It converts gameplay-area DDS textures to PNG, copies the required level
archives, and generates the calibration catalog under:

    paks\
      gameplay_area_calibrations.json
      converted_minimaps\

Pillow handles DDS conversion; FFmpeg is not required.

The application will launch without extracted data, but the map library will
remain empty.

The final layout should be:

    <project>\
      extract_assets.py
      paks\
      worcalc\
      requirements.txt
      war_of_rights_ballistic_ranges.csv

Controls
--------

- Single-click battlefield and mode groups to expand or collapse them.
- Select a map, then click once for the gun and again for the target.
- Drag markers to reposition them; right-click a marker to remove it.
- Cannon, ammunition, and estimation-curve selectors are in the top bar.
- Grayscale and elevation-gradient toggles are below the map.

Troubleshooting
---------------

- "py" not found: install Python 3.12 with the Python Launcher enabled.
- Missing PySide6: rerun the pip install command above.
- Missing worcalc module: run the command from the extracted project root.

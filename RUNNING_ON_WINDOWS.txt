worCalc - Windows
=================

Open artifacts/desktop/worCalc/worcalc-app.exe directly.
The portable ZIP is artifacts/desktop/worCalc-desktop.zip.

Extract the whole ZIP before opening the executable. Keep the resources folder
beside worcalc-app.exe; it contains the offline maps and terrain. Windows needs
the Microsoft Edge WebView2 Runtime for Tauri's embedded interface.

Choose Fire calculator or Sketcher on the entry screen. Both run locally.
Sketcher saves plans in the application's private data folder; Export plans
writes JSON to Downloads, and Import plans reads a previously exported file.

There is no Python setup, browser URL, web server or separate launcher.

To rebuild from source, install Node.js, Rust (the pinned project toolchain),
Microsoft C++ Build Tools and WebView2. Restore native/assets if necessary, then:

    npm.cmd ci
    npm.cmd test
    cargo test --workspace
    npm.cmd run desktop:build

The resulting executable is target/release/worcalc-app.exe. Keep its bundled
resources alongside it when copying the application.

# worCalc 1.1.8 — restore mobile explosion height

Explosion height is visible again in the compact phone layout. It appears in a
small readout above the cannon, ammunition and ground/airburst controls. It uses
the existing calculated height relative to the target and clears when the firing
solution becomes stale. The floating elevation/fuze window stays above the readout.

The desktop status bar keeps its existing metrics. Map alignment, terrain,
ballistics and saved-plan behaviour are unchanged.

Validation covers positive, negative, zero and unavailable explosion heights,
stale-solution clearing, and ground/airburst calculations in the native WebView.
Phone, narrow-phone, landscape and desktop layouts are checked. All 134 frontend
tests and 18 Rust integration tests pass. The Android APK retains the existing
signing certificate for in-place upgrades and all 99 offline maps.

Build provenance: these binaries include validated local changes that have not
yet been committed to the tagged repository source, including the preceding
map-alignment and standalone-app work.

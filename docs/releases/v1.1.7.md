# worCalc 1.1.7 — remove the lingering button shade

Calculator buttons no longer change their fill on hover. This removes the lighter
teal shade that Android can leave on the last tapped button. The earlier focus
changes did not affect this hover fill.

The regression check reproduces the fill change in 1.1.6, then verifies identical
button backgrounds before and after clicks, touch input, hover, pressing and
focus in the updated native WebView. Bold text and compact layout are preserved.
The compiled CSS, page and version metadata were verified byte-for-byte inside
the packaged Android native library. All 132 frontend tests and the Rust workspace
suites pass.

Downloads include the signed Android APK, Windows portable ZIP and SHA-256
checksums. Android retains the existing signing certificate for upgrades.

Build provenance: these binaries include validated local changes that have not
yet been committed to the tagged repository source, including the preceding
map-alignment and standalone-app work.

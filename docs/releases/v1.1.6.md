# worCalc 1.1.6 — neutral button focus

Removes the blue outline from calculator buttons at the CSS source, including
pressed, focused and keyboard-focused states. Native button appearance and shadows
are disabled so WebView button decoration cannot restore the blue highlight.
Keyboard focus uses a plain neutral border. The larger bold text and compact
layout stay unchanged.

Validation covers actual clicks and touch events plus forced hover, pressed,
focus and focus-visible states in the native WebView. Downloads include the
signed Android APK, Windows portable ZIP and SHA-256 checksums. The Android
signing certificate is retained for upgrades.

Build provenance: these binaries include validated local changes that have not
yet been committed to the tagged repository source, including the preceding
map-alignment and standalone-app work.

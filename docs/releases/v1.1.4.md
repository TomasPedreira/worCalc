# worCalc 1.1.4 — compact mobile controls

Gun and Target placement sit beside the map name. A single compact strip switches
Rifled/Smoothbore, Shell/Case and Ground/Airburst without opening Fire controls.
The strip uses the app's neutral buttons and preserves the current selections
when switching cannon family. Advanced settings remain in the map library.

Mobile removes the bottom distance, explosion-height and height-delta panel.
Elevation and fuze stay beside the target in the existing firing window.
The mobile starting view fills the canvas; FIT shows the entire map.

Rifled uses the existing 3-inch Ordnance profile; the Parrott profile has identical
physics. Smoothbore uses the existing 12-pounder Napoleon profile. The native
solver and map pack are unchanged. worSketch retains its individual cannon models.

Downloads: `worcalc-1.1.4-arm64.apk` and `worCalc-1.1.4-windows-x64.zip`.

Validation: the full frontend and Rust workspace suites pass. Native WebView
checks cover phone, landscape and desktop layouts, setting changes, unchanged
mission coordinates, advanced controls and the full-map FIT action. APK version,
existing signing certificate, all 203 offline assets and SHA-256 checksums are
verified. The Windows executable and desktop shortcut point to the current build.

Build provenance: these binaries include validated local changes that have not
yet been committed to the tagged repository source, including the preceding
map-alignment and standalone-app work.

# worCalc 1.1.5 — mobile button styling

Tapped buttons no longer retain the blue keyboard-focus ring. Keyboard navigation
still keeps its visible focus indicator.

Mobile settings, Gun/Target, FIT and Advanced Controls use the existing application
font at 14 px with bold text. The compact layout, neutral button colors and native
calculations are unchanged.

Downloads: `worcalc-1.1.5-arm64.apk` and `worCalc-1.1.5-windows-x64.zip`, with
SHA-256 checksums. Android uses the existing signing certificate for upgrades.

Validation: all 132 frontend tests and the Rust workspace suites pass. Native
WebView checks cover pointer and touch activation, keyboard focus, 14 px bold
text without clipping at 320 px, and phone, landscape and desktop layouts.

Build provenance: these binaries include validated local changes that have not
yet been committed to the tagged repository source, including the preceding
map-alignment and standalone-app work.

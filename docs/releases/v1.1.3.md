# worCalc 1.1.3 — map alignment and terrain corrections

Starting gun markers and terrain-height lookup now use the same corrected map
projection. The 99-map pack includes 60 updated projections; 39 neutral
projections remain unchanged. This includes the verified Miller's Cornfield and
Nicodemus Hill corrections. CSA Drill Camp and barrel calibration are unchanged.

The compass keeps its existing North/East/South/West axes and 15-degree ticks.
Bearings follow the corrected gun-to-target line, so moving a starting gun to its
correct position can change the displayed aim.

Downloads:

- `worcalc-1.1.3-arm64.apk`: Android 7.0 or newer, ARM64, all maps offline. Signed
  with the existing certificate for in-place upgrades from 1.1.2.
- `worCalc-1.1.3-windows-x64.zip`: portable Windows build. Extract the entire folder
  and keep `resources` beside the executable.
- SHA-256 sidecars accompany both downloads.

Validation: 126 frontend tests and 18 native integration tests pass, including
compass cardinal checks, all 99 map entries, 850 gun positions, terrain sampling,
and the independent Miller gun reference. Android version/package/signature and
the bundled alignment catalog are checked; Windows release metadata and the map
pack are verified. No physical-device test is claimed for this APK.

Build provenance: these binaries include the validated local map-alignment and
standalone-app changes, which have not yet been committed to the tagged repository
source. Maps beyond the checked examples still need in-game spot checks.
